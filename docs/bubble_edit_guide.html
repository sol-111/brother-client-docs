03画面対応表▶

page（赤枠：Web Pages）は、URLを持つ1枚の画面です。

04編集方法▶
手順 1画面左上のページ名（index）を選択▶
手順 2一覧から編集対象の画面を選択▶
👀 確認左上の表示が選択した画面名に変わっていることを確認▶
手順 3目のマークが閉じている（非表示の）状態の場合は、選択して表示状態にする▶
👀 確認Group main を展開して表示状態にすると、右側の画面表示が変わることを確認▶
手順 4文言を変更したい箇所を選択▶
手順 5赤枠の入力欄で文言を編集する▶
👀 確認キャンバス上の文言が変わっていることを確認▶
👀 確認テスト環境で該当画面を開き、文言が変わっていることを確認▶

💡 ヒント1つ前の操作に戻したいときは、画面上部の「元に戻す」ボタンを選択▶
05アイビスに報告▶

編集が完了したら、アイビスにメールでご連絡ください。
テキスト変更箇所以外に意図しない変更がないかを確認したうえで、POC環境へ反映します。
